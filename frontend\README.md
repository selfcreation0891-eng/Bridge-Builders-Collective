# Frontend

This directory contains the frontend application for the Bridge Builders Collective platform.

The frontend is responsible for:
- user experience and interface systems
- onboarding and membership flows
- Living Archive interaction layers
- steward dashboards
- governance visibility systems
- H-ROI metric visualization
- consent and safety interaction systems
- media and storytelling presentation
- responsive accessibility-focused design
- institutional trust and continuity experience

Primary stack:
- Lovable
- React
- Node.js
- Supabase integration

The frontend is designed to prioritize:
- clarity
- emotional regulation
- accessibility
- operational trust
- continuity
- long-term scalability
