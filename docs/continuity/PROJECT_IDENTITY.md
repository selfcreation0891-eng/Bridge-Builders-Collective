## Purpose

The Portfolio Control Center is an internal dashboard for tracking the operational state of all Bridge Builders Collective projects. It records truth-state (via the truth ladder), evidence, blockers, decisions, dependencies, handoffs, and reviews for each project. It is not a public Bridge Builders website. It is not a user-facing product.
