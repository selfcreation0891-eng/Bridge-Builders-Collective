# Repository Boundary

## Belongs in this repository

- public home and ecosystem orientation
- verified public governance and trust material
- participation and contribution entry points
- public-facing program discovery
- ecosystem boundary explanations and status
- launch readiness, audit, and activation records

## Referenced here but not duplicated here

- The Living Archive runtime systems
- System Rosetta Stone semantic tooling
- Bridge Builders Academy curriculum delivery
- SOPHIA advisory runtime
- CloseOne and sector-specific implementations

## Excluded until explicitly approved

- duplicate full applications from connected repositories
- hidden governance changes
- unverified legal claims presented as final
- production-readiness claims without evidence
- AI decision authority over people

## Current boundary finding

The repository presently holds **trust, governance, and orientation drafts**, but not the public application itself. Future implementation should strengthen this repository as the front door without swallowing the runtime scope of adjacent ecosystem repositories.
