# Steward Nomination or Application

Template — Pending Ratification (activates with the Steward Eligibility, Orientation, and Appointment Process). No candidacy may be opened under this template before that process is ratified.
Authority: `docs/stewardship/STEWARD_ELIGIBILITY_ORIENTATION_AND_APPOINTMENT_PROCESS.md` §3–4.

Nomination is not selection. This record opens consideration, nothing more. It becomes an active candidacy only when the candidate's informed consent is separately recorded. **This is a private candidate record** — never exposed through public routes (see the privacy section of `STEWARD_APPOINTMENT_AND_ONBOARDING_PROTOCOL.md`).

```text
Candidate name or recorded identity:
Post:
Nomination pathway: (self-nomination / nomination by another / invitation to explore / succession / interim coverage / community recommendation)
Nominator, if any:
Candidate consent: (recorded separately — STEWARD_CANDIDATE_CONSENT_TEMPLATE.md; reference here)
Reason for interest:
Relevant experience:
Lived experience:
Support or accommodations requested: (private; protected)
Conflicts disclosed: (recorded separately — STEWARD_CONFLICT_DISCLOSURE_TEMPLATE.md; reference here)
Privacy acknowledgment: (candidate has received the privacy notice)
Status: (received / consent pending / active candidacy / withdrawn / closed)
```

Field notes:

- **Lived experience** counts as experience. No degree, license, employment, or credential is required (`STEWARD_ELIGIBILITY_STANDARD.md`).
- A nomination by another person creates no obligation; the candidate may decline without explanation.
