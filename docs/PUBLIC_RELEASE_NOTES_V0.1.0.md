# v0.1.0 — Bridge Builders Public Foundation

Release date: pending steward push, CI verification, and deployment (prepared 2026-07-15).

## What this release establishes

- **The canonical public front door** — one static, accessible, dependency-free site built from this repository.
- **Constitutional authority** — the Bridge Builders Constitution v1.0, with a single ecosystem authority order.
- **The canonical ecosystem registry** — one typed registry (25 environments) as the sole source of public names, descriptions, statuses, relationships, and destinations.
- **Universal navigation** — header, mobile menu, footer, cards, related links, and sitemap all generated from the registry and enforced by tests.
- **Initial environment representation** — Bridge Builders Collective, System Rosetta Stone, BridgeBuilders Academy, The Living Archive, SOPHIA, and twenty adopted branches, each with an honest status page.
- **Truthful status declarations** — a public Environment Status Standard; nothing is described as operational without evidence.
- **The trust foundation** — a Trust Center connecting governance, privacy, terms, consent, retention, media licensing, accessibility, incident response, steward escalation, archive integrity, SOPHIA boundaries, and the public claims standard.
- **Initial participation pathways** — reading pathways that work today, and an honest statement of the submission pathway still to be opened.

## What this release is not

v0.1.0 is **not the complete ecosystem**. Environments remain, by their own public labels:
in development (the front door itself, System Rosetta Stone, Public Knowledge, Contribution)
and planned (BridgeBuilders Academy, The Living Archive, SOPHIA, and all named branches).
Nothing is yet public-preview, steward-pilot, or invitation-required — those statuses require
evidence this release does not claim.

## Known honest gaps (tracked)

No contact email or open submission channel yet (B-EXT-7); no domain or hosting yet (B-EXT-4/5);
policy effective dates and retention periods pending steward completion (C-007);
no human screen-reader audit yet (accessibility review).
